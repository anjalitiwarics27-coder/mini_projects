## 🚀 Getting Started

### 1. Clone the repository
\`\`\`bash
git clone https://github.com/anjalitiwaris27-coder/projects.git
cd projects
\`\`\`

### 2. Navigate into any project folder
\`\`\`bash
cd task1/LoanEMICalculator
\`\`\`

### 3. Run it 🎉
\`\`\`bash
python main.py
\`\`\`

> 💡 Replace \`main.py\` with the actual filename inside each project folder.
