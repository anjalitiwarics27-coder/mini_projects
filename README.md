# 📁 Projects

A collection of Python mini-projects built for practice — covering calculators, APIs, web apps, games, and contact management.

## 🧩 Tasks

| # | Project | Description |
|---|---------|-------------|
| 1 | [Loan EMI Calculator](./task1/LoanEMICalculator) | Calculates monthly EMI based on principal, interest rate, and tenure. |
| 2 | [API Fetcher](./task2/Api_Fetcher) | Fetches and displays data from a public API. |
| 3 | [Blog App](./task3/blog_app) | A simple blog application to create and view posts. |
| 4 | [Guessing Game](./task4/gussing_game) | A number-guessing game with user interaction. |
| 5 | [Contact Book](./task5/contact_book) | Add, view, update, and delete contacts. |

## 🛠️ Tech Stack

- **Python** — core logic for calculators, games, and API handling
- **HTML** — front-end for the blog app / contact book

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/anjalitiwaris27-coder/projects.git
cd projects
```

Navigate into any task folder and run the Python file:

```bash
cd task1/LoanEMICalculator
python main.py
```

> Replace `main.py` with the actual entry-point filename inside each folder.
